# Flag asset notice

LocaleGuard uses ISO 3166-1 alpha-2 country identifiers for display flags. Country flags are public-domain symbols in the source dataset supplied for this project (`svg-country-flags`, Hampus Nilsson, license `PD`).

The bundled `us.svg`, `es.svg`, `de.svg`, and `jp.svg` files are compact SVG renderings used only as presentation metadata. Language identity is always determined by the configured language code; flags are never used as language identifiers.
